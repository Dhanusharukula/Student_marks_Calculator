# Student Marks Calculator

A simple Python project that calculates a student's total marks, percentage, and grade based on marks entered for different subjects.

## Features
- Input marks for multiple subjects
- Calculate total marks
- Calculate percentage
- Display final grade
- Simple and easy-to-use interface

## Technologies Used
- Python

## How to Run
1. Clone this repository.
2. Open the project folder.
3. Run the Python file:
   ```bash
   python student_marks_calculator.py
   ```
4. Enter the student's marks when prompted.
